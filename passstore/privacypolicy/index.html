Privacy Policy

Last Updated: November 25, 2026

This Privacy Policy describes how PassStore ("we", "our", or "the Application") handles user information. We are committed to protecting your privacy and ensuring complete transparency regarding how the Application operates.

1. Information Collection and Use

s PassStore is designed as an offline-first application.

  • No Server Data Collection: We do not collect, transmit, store, or process any personal data, usage analytics, crash reports, or device identifiers on external servers.
  • Local Storage Only: All data you create, input, or manage within the Application is stored exclusively in the local storage of your Android device. We have zero access to your stored records.

2. Device Permissions

Depending on the features you choose to use, the Application may request standard Android system permissions strictly for local device functionality:

  • Storage / File Access: Used solely when you manually export or import backup files (such as CSV or database backups) to and from your device's local storage.
  • Biometric / Device Authentication: Used strictly on-device via the standard Android system API (BiometricPrompt) to unlock the Application locally. Biometric data is handled entirely by your device's operating system and is never read or stored by the Application.

3. Third-Party Services

The Application does not integrate third-party advertising SDKs, behavioral tracking tools, or cloud analytics services that collect user data.

4. Data Security and Backups

Because all application data resides locally on your device, you retain full control over your information. Uninstalling the Application or clearing its app data through Android Settings will permanently delete all locally stored records unless you have manually created an external backup file.

5. Children's Privacy

The Application does not knowingly collect any personal information from anyone, including children under the age of 13.

6. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect feature updates or regulatory requirements. Any changes will be posted on this page with an updated revision date.
